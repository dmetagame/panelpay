# PanelPay decision rail

PanelPay gives a team one campaign sheet and a public trail of decisions. Its signature is a vertical budget rail: terms lock at the top, applicants branch into admit/skip/wait, and the paid path ends in an inspectable receipt. The interface is an invitation and a working docket, never a portfolio dashboard.

- Canvas: cool chalk `#f1f5f4`; text: deep petrol `#183d47`; primary accent: orange `#e45b32`; success: dark teal `#196b57`.
- Typography: locally served IBM Plex Sans for prose, IBM Plex Mono for amounts and evidence. Large light-weight proposition; plain 16px form labels and text.
- Composition: asymmetric 7/5 hero, one wide campaign sheet, then individual contribution rows. Hairlines and generous spacing; no card grid or decorative gradients.
- Controls: 48px minimum action targets, native labelled fields, explicit pending/error states and visible focus. Mobile is a single reading column.
- Public evidence: full terms, agent rationale, owner-signed completion, fixed amount, locked address, chain transaction. Internal/unverified classifications appear beside the evidence.
- Motion: brief state transitions only; respect reduced motion.

Applied `frontend-design` skill. Outlay provides the quality standard; this product uses its own palette and interaction.
